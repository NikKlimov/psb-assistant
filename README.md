# ПСБ · ассистент по розничным продуктам

Прототип поискового ассистента по публичным страницам `www.psbank.ru`. Он собирает страницы вкладов, кредитов и банковских карт с учетом `robots.txt`, сохраняет подтвержденные условия в SQLite и отвечает на вопросы со ссылкой на источник каждого факта.

## Запуск

Требуется Python 3.11+ или Docker.

```powershell
Copy-Item .env.example .env
docker compose -p psb-assistant up --build
```

Откройте <http://localhost:8000>. Первое обновление каталога выполняется в фоне. Для локального запуска без Docker:

```powershell
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
.venv\Scripts\python -m psb_assistant serve
```

Если в вашей сети используется корпоративный TLS-прокси, оставьте `REQUESTS_CA_BUNDLE=artifacts/psb-ca-bundle.pem` в `.env`. Compose подключает каталог `artifacts` в контейнер только для чтения. Без этого параметра Docker использует системное хранилище сертификатов.

Обновление можно запустить вручную:

```powershell
python -m psb_assistant crawl
python -m psb_assistant crawl --force-update
```

Последняя команда игнорирует 24-часовой кеш. По умолчанию `LLM_PROVIDER=extractive`: приложение отвечает непосредственно сохраненными выдержками и не требует ключа. Доступные адаптеры — `gigachat`, `yandex`, `openai` и `ollama`; переключение выполняется в `.env`, без изменения Python-кода. Для GigaChat ключ авторизации обменивается на короткоживущий access token, который не сохраняется на диске. Для Yandex AI Studio нужны API-ключ и ID каталога.

## Как это устроено

`crawler.py` проверяет правила `robots.txt`, открывает три каталога ПСБ, страницу накопительного счета и дальневосточную ипотеку, а затем передает HTML в специализированный парсер. `http.py` ограничивает частоту запросов, повторяет временные ошибки `429/5xx` с экспоненциальной задержкой и не разрешает уходить с домена банка. `cache.py` хранит HTML и разобранный продукт в SQLite; свежая запись переиспользуется 24 часа.

`parsers/base.py` ограничивает разбор блоком `.page__content`, удаляет навигацию и рекомендации, а условия берет из строк таблиц и `dl` с сохранением пары «название — значение». Если этот блок исчезнет, остается мягкий разбор по ключевым словам с логированием `selector_broken`. `deposits.py`, `loans.py` и `cards.py` задают словарь параметров для соответствующей категории. Запись публикуется в кеш только после успешной валидации. `scripts/reparse_cache.py` позволяет повторно разобрать уже сохраненный HTML без нового запроса и без изменения исходной даты загрузки.

`service.py` выполняет поиск, передает релевантные выдержки LLM и сверяет ее JSON с исходным снимком. Pydantic запрещает лишние поля и внешние ссылки. GigaChat и YandexGPT используются как селекторы источников: даже если модель переформатировала строку таблицы, факты в пользовательский ответ проецируются обратно из проверенного SQLite-снимка. Если провайдер пусто ответил или применил фильтр, включается резервный провайдер или безопасный extractive-ответ. При невалидном JSON выполняются два повтора с температурой `0.0`; после этого возвращается ошибка без непроверенных данных. Сравнение дополнительно формирует объяснение различий с фактами-источниками и задает вопросы о сумме, сроке, валюте, пополнении и снятии; автоматический победитель без этих данных не объявляется.

## Переменные окружения

```dotenv
LLM_PROVIDER=gigachat         # extractive | gigachat | yandex | openai | ollama
LLM_FALLBACK_PROVIDER=extractive
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
OLLAMA_BASE_URL=http://host.docker.internal:11434
OLLAMA_MODEL=qwen2.5:7b
GIGACHAT_CREDENTIALS=
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_BASE_URL=https://api.giga.chat/v1
GIGACHAT_AUTH_URL=https://ngw.devices.sberbank.ru:9443/api/v2/oauth
GIGACHAT_MODEL=GigaChat-3-Ultra
YANDEX_API_KEY=
YANDEX_FOLDER_ID=
YANDEX_BASE_URL=https://ai.api.cloud.yandex.net/v1
YANDEX_MODEL=yandexgpt-5.1
CACHE_PATH=data/cache.sqlite3
CRAWL_DELAY=2
AUTO_CRAWL=true
```

Ключи не коммитятся. Если корпоративная сеть подменяет сертификат, задайте `REQUESTS_CA_BUNDLE` на доверенный PEM-файл; отключение проверки TLS в приложении не используется.

## Проверки

```powershell
.venv\Scripts\python -m pytest -q
.venv\Scripts\python -m ruff check psb_assistant tests
```

Тесты проверяют мягкий парсинг, обязательные ссылки, срок кеша и переключение на резервную модель после фильтрации.

## Ограничения прототипа

Сравнение показывает подтвержденные параметры и предупреждает о валюте, сроке и сценарии снятия. Финансовый расчет доходности намеренно не делается без суммы, срока, налогового статуса и правил досрочного расторжения. Динамические данные, доступные только после выполнения JavaScript, должны быть вынесены в отдельные официальные HTML/PDF-источники и подключены отдельным парсером.
